# School Management System – Frontend

Next.js frontend for the school management system. Requires the backend API to be running.

## Setup

1. Copy `.env.local.example` to `.env.local` and set `NEXT_PUBLIC_API_URL` to your backend URL (e.g. `http://localhost:8000`).
2. Install dependencies and run the dev server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000). If the backend is not yet configured, you will be redirected to the setup page to set school name and create the first admin account.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
